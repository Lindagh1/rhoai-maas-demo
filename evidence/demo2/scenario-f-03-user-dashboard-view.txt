## Real finding

The non-admin end-user dashboard shows, per subscription/model:
  - subscription name
  - number of active API keys tied to it
  - the CONFIGURED token-rate-limit ceiling (e.g. "2,000 / 1 minute")

It does NOT show, anywhere in this UI (checked both Subscription view and
Model view, both collapsed and expanded):
  - actual token/request consumption so far
  - remaining quota in the current window
  - any usage history, graph, or chart
  - any indication of how close the user is to their limit

This means: as a non-admin user, the ONLY way to discover you have been
rate-limited is to actually make a request and receive an HTTP 429 (see
evidence/demo2/scenario-e-03-rate-limit.txt) — there is no proactive
visibility into consumption from the dashboard itself. This is a genuine,
verified product limitation as of RHOAI 3.5's MaaS UI, not an assumption.
